# Монтаж видео

Все пути ниже относительно корня репозитория. Применяй общие правила AGENTS.md.

Прочитай docs/editing-workflow.md и монтажный бриф. Проверь доступный редактор и исходники. Собери edit plan с оригинальными source ranges, длительностями, скоростью, crop и переходами. Запиши timeline in/out, handles и правило повторов.

Сначала собери смысловой rough cut. Затем уточни музыкальные акценты, переходы и скорость. Не скрывай нехватку материала случайным повтором. При изменении скорости отдельно проверь звук и движение. После overlapping transitions пересчитай длину и проверь реальные границы сцен.

Задай единую colour pipeline по метаданным источников. Корректируй экспозицию и баланс между сценами до применения общего look. Для HDR/SDR проверь фактическое преобразование, а не только tags.

Экспортируй в новый файл с настройками под устройство. Проверь финальный файл по video-review. Если инструментов для рендера нет, передай выполнимый план и явно обозначь, что видео не экспортировано. Сохрани исходники и прошлые версии.
