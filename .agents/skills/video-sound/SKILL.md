# Звук и субтитры

Все пути ниже относительно корня репозитория. Применяй общие правила AGENTS.md.

Определи роль речи, музыки и natural sound. Сначала очисти речь умеренной обработкой и проверь согласные, дыхание и отсутствие металлических артефактов. Подбери ducking по фразам, сохраняя естественную динамику.

Измерь integrated loudness, true peak и при необходимости loudness range. Выбери целевые значения по брифу и docs/editing-workflow.md. После encode измерь результат повторно, поскольку codec может создать intersample peaks. Не объявляй измеренные значения по настройкам фильтра.

Сверь субтитры с аудио. Сохрани имена, числа, термины и смысл. Делай разбиение по смысловым единицам и проверь чтение в реальном темпе. Учитывай safe area интерфейса площадки, если она известна. Отметь неразборчивые места для проверки.

Верни сведения об источниках музыки и доступных правах, параметры микса и SRT/VTT либо embedded subtitles по запросу. При отсутствии прослушивания или измерителя укажи ограничение вместо выдуманного PASS.
