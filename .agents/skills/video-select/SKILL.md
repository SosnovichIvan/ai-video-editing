# Отбор исходников

Все пути ниже относительно корня репозитория. Применяй общие правила AGENTS.md.

Сначала инвентаризируй доступные файлы и метаданные по docs/editing-workflow.md. Дай каждому оригиналу устойчивый source ID. Свяжи proxies и транскоды с оригиналами.

Просмотри движение и прослушай звук в кандидатах. По одному thumbnail нельзя подтверждать пригодность движения. Запиши source in/out [in, out), содержание, качество, ограничения и роль в истории. При отсутствии просмотра пометь selection как предварительный.

Выбирай выразительные моменты с достаточными handles для переходов. Для задачи с уникальными моментами проверь пересечения оригинальных диапазонов, включая handles и копии файла. Несколько непересекающихся фрагментов одного файла допустимы.

Выдай таблицу отбора и причины исключений, влияющие на результат. Переходи к монтажу только в рамках запроса. Используй templates/edit-plan.md для передачи selection.
